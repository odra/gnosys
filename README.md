# Gnosys

An attempt at creating a "Language Model build system" (if such a thing makes sense), for educational purposes.

Most of the work and source code is inspired from the following book: `Rashka, Sebastian. 2025. Build a Large Language Model. Manning. ISBN: 9781633437166`

## Repository Structure

* `data`: data files used by the project (i.e training text files, etc)
* `gnosys/`: project source code
* `images`: Containerfiles used in this project
* `scripts`: tooling and random script files

## References

* `Rashka, Sebastian. 2025. Build a Large Language Model. Manning. ISBN: 9781633437166`

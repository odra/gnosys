# Gnosys Source Code

## Structure

* `src/gnosys/`: the "core mini framework" to create build systems and other tools
* `src/gnosys_llmbs/`: A "LLM Build System" that uses `src/gnosys`, based on `Rashka, Sebastian. 2025. Build a Large Language Model. Manning. ISBN: 9781633437166`
* `test/`: pytest files to test all source code from `src/`
